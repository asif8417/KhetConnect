# KhetConnect

KhetConnect is a farmer-focused digital marketplace that connects farmers with buyers.

## Project Vision
To help farmers access better market opportunities through digital technology and AI-powered insights.

## Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- AI/ML: Python (planned)
